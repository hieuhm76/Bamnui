# Bamnui

Phần mềm tập bấm nút phát biểu tại Quốc hội.

## Chạy ngay trên trình duyệt

1. Mở file `index.html` trong trình duyệt, hoặc
2. Chạy local server:

```bash
python -m http.server 8000
```

Sau đó mở:

```text
http://localhost:8000
```

## Deploy lên website

Bạn có thể deploy repo này lên GitHub Pages, Netlify hoặc Vercel bằng cách giữ nguyên file `index.html` ở thư mục gốc.

## Mô tả

Đây là phiên bản web của trò chơi "Bấm nút phát biểu" giúp người dùng luyện phản xạ bấm STOP khi đồng hồ đạt đúng 10 giây.
